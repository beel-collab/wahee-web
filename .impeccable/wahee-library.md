# Wahee library

Routes: `/`, `/quran`, `/hadith`, collection/book/reading/search/saved routes, `/seerah`, `/duas`.
Mode: Operate for finding a passage; Read for the passage itself.

## Direction contract

THESIS: A front door to the existing Quran and a usable Hadith library. Find a collection, follow its book structure, and read a numbered passage with its source context.

OWN-WORLD: Extend Wahee's established white/near-black reading surfaces, original #367b6c green, Georgia headings, clear sans controls, Scheherazade New Arabic, and Nastaliq Urdu. Fine rules and quiet surfaces; no invented book-cover artwork or new identity.

STORY: Home gives Quran and Hadith the main reading entrances, with quieter Seerah and Duas placeholders. The Hadith index explains available languages; each collection exposes its own book index. A passage retains collection/book context and previous/next navigation.

FIRST VIEWPORT: Home has a short editorial heading, two generous reading entrances side by side on desktop and stacked on mobile, then two compact upcoming-section rows. Hadith has a left aligned title, search, and a ruled collection directory. Reader puts the source reference and language controls before a generous single text column.

FORM: Direct extension of the existing directory/reader system. User specified the four-section structure and delegated the Hadith design. No replacement visual world or concept tournament. Signature interaction: select a book, read a passage, and return to that book's numbered range. Preserve theme and local preferences. Motion stays limited to existing reduced-motion-aware scroll and subtle control feedback.

Reading detail: selected translations lead, with the complete Arabic source expandable above them. Arabic-only reading shows the source continuously. This keeps long narration chains available without pushing the chosen translation several screens down on mobile. Source narrators retain their actual script and Urdu font even when attached to an English translation row.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
