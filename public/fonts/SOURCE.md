# Font sources

- Noorehira Regular 2.001: Abu Saad / Noor-e-Hidayat, https://www.noorehidayat.org/. Original unmodified font, retrieved 2026-10-21 from the distribution at https://islamicurdubooks.com/download/fonts.zip (linked from https://islamicurdubooks.com/fonts.php). The author's download endpoint was unavailable. SHA-256: `012d33c47306e63850d4db08a5f94191cba679aa90510aeaedffe8209eaa3f31`. The embedded license explicitly permits free distribution with or without an application; its full text is supplied as `Noorehira-LICENSE.txt`. Used for the Arabic wordmark and Quran reading, word meanings, names and context. It natively supplies the requested two-eyed initial/medial U+06C1 and draws the source's U+066A code as a ruku marker (ع). No font building, glyph modification, or letter substitution is used.
- Scheherazade New Regular 4.500: SIL Global, https://github.com/silnrsi/font-scheherazade/releases/tag/v4.500. Retrieved 2026-10-20 from the official release archive. Distributed unmodified with `Scheherazade-OFL.txt`. Used for Hadith and general Arabic display.
- Noto Nastaliq Urdu: existing bundled Urdu font; see `Nastaliq-OFL.txt`.
- Amiri Quran: historical bundled font, no longer used by the active app. See `Amiri-OFL.txt`.
