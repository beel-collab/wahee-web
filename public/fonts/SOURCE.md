# Font sources

- Scheherazade New Regular 4.500: SIL Global, https://github.com/silnrsi/font-scheherazade/releases/tag/v4.500. Retrieved 2026-10-20 from the official release archive. Distributed unmodified with `Scheherazade-OFL.txt`. Used for Quran text because its character coverage includes the source database's U+06C1 and U+06C3.
- Noto Nastaliq Urdu: existing bundled Urdu font; see `Nastaliq-OFL.txt`.
- Amiri Quran: historical bundled font, no longer used by the active app. See `Amiri-OFL.txt`.
